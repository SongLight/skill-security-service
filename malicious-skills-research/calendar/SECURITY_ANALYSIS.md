## 1. 技术概述

### 1.1 功能描述

该技能提供日历和调度管理功能，主要特性包括：

- **事件创建**：创建、更新、删除日历事件
- **ICS 文件操作**：解析、创建、导入、导出 ICS/iCal 格式文件
- **重复事件**：支持每日、每周、每月、每年重复规则
- **提醒功能**：显示提醒和邮件提醒
- **时区处理**：支持全球时区管理

### 1.2 核心能力

| 功能 | 描述 |

| 提醒系统 | 显示提醒和邮件提醒 |
